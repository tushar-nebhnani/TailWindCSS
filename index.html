// 01   what is chai-css

CSS utilities,
the terminal way.

Chai CSS is a utility-first styling engine that reads your HTML, detects chai- prefixed classes, and applies the corresponding CSS properties directly to your elements — live, in the browser.

Think Tailwind, but instead of a build pipeline you get a live playground with a terminal UI, an applied-styles log, an error reporter, and a live preview iframe — all in one file.

index.html
<!-- before chai --> <h1 style="padding:2rem;color:red">   Hello </h1>   <!-- after chai --> <h1 class="chai-p-8 chai-t-red">   Hello </h1>   <!-- chai resolves: --> ✓ padding → 8px ✓ color → red
// 02   why chai-css

No setup. No surprises.

Built for developers who want to prototype fast, inspect styles live, and never fight a build tool again.

⚡
Zero Config
No webpack, no PostCSS, no tailwind.config.js. Paste your HTML, run the script, done.
🔍
Live Inspector
Every applied class shows up in the APPLIED STYLES panel with an eye toggle and a remove button — inspect and tweak without touching code.
🛑
Error Reporter
When a class doesn't map to anything valid, Chai tells you exactly what went wrong and why — no silent failures.
🎯
Conflict-Free
The chai- prefix namespaces every class so it never collides with Bootstrap, Tailwind, or your own CSS.
👁
Live Preview
Your HTML renders in an iframe the moment you hit Run Script. Toggle styles on/off and watch the preview update in real time.
🖥
Terminal Native
The entire UI is styled as a macOS terminal window. If you live in the CLI, you'll feel right at home.
// 03   how it works

Three steps to styled.

Chai reads your markup, maps utility classes to CSS properties, and injects the styles — all in the browser, no server required.

01
Write HTML
Add chai-{property}-{value} classes to any element in the HTML input panel or upload a file.
02
Hit Run Script
Chai parses every element, looks up each class in its database, validates the value, and applies the CSS property inline.
03
Inspect & Tweak
Applied styles appear in the log with eye and remove controls. Errors surface in the failed panel with a reason. Preview updates live.

// 05   class syntax

chai-{key}-{value}

Every class follows the same pattern. The key maps to one or more CSS properties. The value is applied as-is for visuals, or converted to px for spacing and layout.

Class CSS Property Resolved Value Category
chai-p-8 padding 8px spacing
chai-bg-red background-color red visuals
chai-t-white color white visuals
chai-br-4 border-radius 4px visuals
chai-flex display flex layout
chai-o-50 opacity 50 visuals
